# World plan: orchestration of the Feelio journey (supersedes ART_DIRECTION §3–5b once approved)

> **Status: future work.** The current scope is the interactive global map (`docs/MAP.md`). This plan describes how per-place maps and extra chapters will be built later. All images are generated by the owner in ChatGPT through `docs/ASSET_PROTOCOL.md`; Claude Code only writes the prompts.


Why this exists: single-image strips come out as generic scenery with no recognisable places. Fix: the world is built from four layers, and the places (School, Home, Park, Club, Market) are real landmark sprites placed by data.

## 1. The four layers
| Layer | What | Made by |
|---|---|---|
| L0 Ground strip | Lawn, winding trail, 5 empty round pads, trees and flowers. No landmarks. Same seam contract for every strip. | Image model (once per zone, or one reusable base) |
| L1 Landmarks | 1 hero building (the place itself) + 4 props (one per level) as separate sprites on plain background | Image model, reference-guided, one sprite sheet per zone |
| L2 Game UI | Level numbers, stars, locks, glow, dashed route, zone banner, fog, soft shadows under sprites | Code, driven by `world.json` |
| L3 Mascot | Marker on current pad, walking, face states, tap to talk, reactions | Official mascot + approved generated poses, code-animated |

A new place = 1 hero sprite + 4 prop sprites + 1 JSON entry (+ optional new ground strip). No redesign, no code change.

## 2. Seam contract (never break it)
- Strip is 2:3 portrait (ChatGPT output 1024×1536; finals about 816×1224, WebP, 400 KB or less). If 9:16 is wanted later, crop the sides. Trail enters at the exact horizontal centre of the bottom edge and leaves at the exact centre of the top edge, same width and colour.
- Top 8% and bottom 8% are plain light-green lawn with only the trail crossing.
- Same camera in everything: high-angle three-quarter view, light from the top-left.
- 5 pads per strip, alternating left and right.

## 3. Child-first UX rules
- One path, no forks, no text needed (icons + voice from the mascot).
- Tap targets 72 px or more; the current pad pulses; the map auto-scrolls to it.
- Locked pads sit under fog, never in an error state. No fail states: stars, not scores.
- Bottom phone-style nav with 4 big icons: Map, Talk, Stories, My collection.
- The hero landmark of a zone is large (about 40% of strip width) so a child recognises "school" instantly.

## 4. Mascot on the map
- Marker on the current pad with idle bounce and soft shadow; hops along the trail to the next pad on completion (path from data).
- Face states: happy (level done), excited (new unlock), calm/sad (scenario moments), listening/speaking (voice).
- Tap the mascot = open the voice companion. It is visibly an AI creature, which supports the AI-disclosure rule.
- Arrival moment: when a zone unlocks, the mascot walks to the hero landmark and "enters" (door opens, short animation).
- Companions (heart, cloud, star) appear on completed pads as collectibles and fill "My collection".
- Poses are generated one at a time from the official mascot as reference, owner-approved, logged (see CLAUDE.md rule 10 change).

## 5. world.json (shape)
```json
{
  "pack": "base",
  "zones": [{
    "id": "park", "order": 1,
    "ground": "ground_01.webp",
    "hero": {"sprite": "park_hero.webp", "x": 0.72, "y": 0.10, "scale": 0.42},
    "levels": [
      {"id": "park-1", "pad": {"x": 0.50, "y": 0.92}, "prop": {"sprite": "park_swings.webp", "x": 0.22, "y": 0.88}, "scenario_ids": ["..."]}
    ]
  }]
}
```
Coordinates are fractions of the strip so they survive resizing. Pad positions are measured once per ground strip and reused.

## 6. Pipeline (do in order, approve at each gate)
1. **Mascot refs.** Collect front view, 4 faces, 4 colourways in `brand/`. Generate the pose sheet (section 8). Gate: owner approves poses.
2. **Style anchor.** Generate the ground strip (7A) ×4, pick one. Generate the Park hero and props (7B, 7C). Gate: owner approves the look.
3. **Compose test in code.** Place ground + hero + props + pads + mascot from a draft `world.json`. Check seams by stacking two strips. Gate: it reads as a game to a child.
4. **Other zones.** Reuse the approved ground strip and the anchor as `reference_images`. Generate hero and props per zone.
5. **QA.** Run the rejection checklist: no text/letters, no people, no logos, correct camera, sprites fully inside frame, plain background, brand colours.
6. **Log.** Every image into `assets/manifest.json` (prompt, tool, date, chat link, approved).

Tool: ChatGPT image generation (manual, by the owner). Claude Code cannot call it; using the OpenAI image API would be a new paid service and needs the owner's approval first.
ChatGPT working rules:
- Output sizes are fixed (1024×1536, 1024×1024, 1536×1024): use 2:3 for strips and 1024×1024 for sprites.
- One chat per job (ground strip, each zone's landmarks, mascot poses) to keep the style locked.
- Upload the approved strip or the official mascot as reference and say "same art style, same camera, same colours".
- Edit instead of regenerating: "keep everything else identical, only change X".
- Ask 3–4 times per image and pick the best; there is no seed.
- Sprites: ask for a transparent-background PNG; if it returns white or a checkerboard, remove the background afterwards.
- It cannot place the trail exactly at the edge centres: check every strip and fix by cropping or editing.
- Log each image by hand in `assets/manifest.json` (prompt, date, chat link, approved).

## 7. Prompts

### Shared style block (put first in every prompt)
> Create an image. Flat 2D vector illustration for a children's mobile game, soft pastel gradients, clean rounded shapes, minimal shading, friendly kawaii style matching a glossy cartoon mascot; not 3D, not photorealistic. High-angle three-quarter view, light from the top-left. Palette: fresh greens with warm amber, rose pink, lilac and sky-blue accents. Culturally neutral, temperate setting.

### 7A. Ground strip (no landmarks)
> [Shared style block] Tall 2:3 vertical portrait level-map background, ground only. A single wide, smooth, light-beige trail winds in a gentle S-curve from the bottom edge to the top edge, entering at the exact horizontal centre of the bottom edge and leaving at the exact horizontal centre of the top edge (the trail must touch the exact centre of both edges), same width at both ends. Along the trail are exactly 5 large, flat, empty, round stone pads, evenly spaced, alternating left and right, each slightly lighter than the trail, with nothing on them. Large open areas of lawn on both sides with subtle mown stripes, a few small trees, bushes and flower beds near the edges only, leaving big empty spaces beside each pad for landmarks to be added later. The top 8% and bottom 8% are plain light-green lawn with only the trail crossing. No buildings, no fences, no objects, no numbers, no buttons, no stars, no people, no faces, no text, no letters, no logos, no watermark.

### 7B. Hero landmark (one per zone, 1024×1024, plain background)
> [Shared style block] A single large [HERO] as a game sprite, fully inside the frame, centred, transparent background PNG (plain white if transparency fails), no ground shadow, no extra objects, no people, no text, no letters, no signs with writing, no logos.

Hero descriptions:
- **Park:** a big friendly shady tree with a bench and a hanging swing, beside a small round pond with a wooden bridge.
- **Home:** a cosy family house with the roof and front wall cut away like a dollhouse, showing a child's bedroom with a bed, a porch with a front door, a small chimney.
- **School:** a primary school building with a round clock, double entrance doors, a small bell tower, bright roof; no letters on the clock face.
- **Club:** a colourful community clubhouse with a curved roof, round windows, bunting, and a small stage porch; an easel and a drum stand beside it.
- **Market:** three market stalls in a row with colourful striped awnings, crates of bread, fruit and flowers, a small fountain in front.

### 7C. Props sheet (4 props, one level each)
> [Shared style block] A sprite sheet of exactly 4 separate game props in a 2×2 grid, each fully visible with generous space between them, transparent background PNG (plain white if transparency fails), no ground shadow, nothing touching: [PROP 1]; [PROP 2]; [PROP 3]; [PROP 4]. No people, no text, no letters, no logos.

Props per zone (level theme in brackets):
- **Park:** swing set with slide [waiting for a turn]; round pond with ducks [calming down]; grassy ball field with ball and goal [losing a game]; picnic table with basket [sharing].
- **Home:** garden gate with mailbox [going out to play]; porch with front door [leaving for school]; kitchen table cutaway room [family talks]; living room with sofa cutaway [sharing with a sibling].
- **School:** school gate with bench [first day]; classroom with grouped desks cutaway [nervous about a test]; reading corner with cushions under a small tree [being left out]; lunch benches [making a friend].
- **Club:** clubhouse entrance with benches [joining, feeling shy]; music corner with piano, drum, xylophone [taking turns]; art corner with easels and paint pots [feedback]; board game table with blocks on a rug [teamwork].
- **Market:** bakery stall [waiting in line]; toy stall [wanting what you can't have]; fountain plaza [feeling lost]; fruit stall [honesty].

The hero is the fifth level of each zone (Park: tree bench, helping someone sad; Home: bedroom, bedtime worries; School: playground, arguing with a friend; Club: stage, stage fright; Market: flower stall, kindness).

### 7D. Quick all-in-one test (single image, to compare)
> [Shared style block] Tall 2:3 level-map of a school area. A winding beige trail with 5 empty round stone pads runs from the bottom centre to the top centre. A very large school building with a round clock occupies the top third; four smaller clearly recognisable props sit beside the trail pads: a school gate with a bench, a classroom cutaway with desks, a reading corner with cushions, lunch benches. Every object belongs to a school. Top and bottom 8% plain lawn. No numbers, no people, no text, no letters, no logos.

If 7D shows the right places, you may skip L1 for that zone. If it does not, use the layered route.

## 8. Mascot pose prompt
> I have attached the official mascot. Keep this exact character from the reference image, same design, proportions, colours, antenna with amber orb, dark blue screen face with sparkle eyes, pink cheeks, heart on the belly, glossy kawaii vector style. Change only the pose: [POSE]. Keep the face [EXPRESSION]. Full body, centred, transparent background PNG (plain white if transparency fails), no shadow, no props, no text, no other characters.

Poses: walking left, walking right, jumping, waving, pointing, celebrating, sitting, listening (head tilt), thinking, speaking, sleeping. If the face drifts, generate the body only and overlay the real face templates.
