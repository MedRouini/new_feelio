# My room Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Replace the "My collection" treasure-room page with **My room**: the child's bedroom, where their character can be dressed in items unlocked by stories, feelings and levels, and their name, colour and likes can be changed.

**Architecture:**
- **Data and rules:** the wardrobe and unlock maths are client-safe data and pure functions (`content/room/wardrobe.json`, `child/wardrobe.ts`).
- **Server:** a server-only module (`child/room.ts`) works out the room state from data the app already stores, and applies every change through one strict route (`/api/child/room`). It refuses locked items there, not just in the UI.
- **Page:** the room (`/room`) is a client scene. Objects grow into full-screen close-ups through shared-layout transitions (motion `layoutId`). Positions come from a data file, measured from the room art.

**Tech Stack:** Next.js 16 (App Router, Turbopack), React, TypeScript, motion/react, next-intl, Drizzle + Neon Postgres, zod, Vitest (node), Playwright.

**Spec:** `docs/superpowers/specs/2026-10-13-my-room-design.md`

## Global Constraints

- **Priorities:** child safety > emotional usefulness > brand consistency > UX quality > number of features (CLAUDE.md).
- **Fluidity and layout are the owner's top priority.** Animate only `transform` and `opacity`. Every motion has a reduced-motion version (`useCalm()`). No overlaps or clipped text at 1180×820, 1920×920 and 390×844, in English and Arabic.
- **Child UI:** touch targets of at least 72 px (`--touch-child`), no shadows, no blur, no failure states, minimal reading (audio and icons), one primary action per close-up.
- **Nothing typed by the child is stored or sent.** Names come only from `content/nicknames.json` or `"parent"` (the parent's nickname).
- **Server-side enforcement (rule 2):** locked items, wrong body areas, unknown ids and `seen > reached` are refused by the server.
- **No pressure (rule 12):** no streaks, no daily rewards, no timers, nothing lost by staying away. Unlocks never go down.
- **Art (rule 10):** only approved assets render; undelivered ids show the grey `TODO(PLACEHOLDER)` box automatically (`AssetImage`). Claude Code draws nothing.
- **i18n:** every string in `messages/en.json` and `messages/ar.json`. Logical CSS properties only. Art and the character are never mirrored.
- **Commits:** author is the repo-local git identity; **no `Co-Authored-By` trailer** (owner rule). Work on branch `my-room`.
- **Commands:** `npm run lint`, `npx tsc --noEmit -p .`, `npx vitest run`, `npx playwright test` (needs the dev server on port 3000), `npm run db:generate`, `npm run db:migrate`, `npx tsx scripts/build-assets.ts`.

## Review Focus

1. **A parent deletes stories after an item unlocked:** the item stays unlocked and still worn. Pinned in Task 4 ("deleting stories never lowers reached").
2. **A child double-taps the gift box while the request is in flight:** only one unlock is used per tap, and `seen` never passes `reached`. Pinned in Task 4 (repeated `seen` calls) and Task 7 (the button is disabled while busy).
3. **A worn item's art is not delivered yet:** the character renders without it (no grey box on the body), while the wardrobe tile shows the placeholder. Pinned in Task 2 (the `wornLayers` unit test).
4. **A parent removes their nickname after the child chose "parent":** the room falls back to no name sign and offers the list. Choosing "parent" is refused while no parent nickname exists. Pinned in Task 4.
5. **Stories switched off by the parent:** the book stack is hidden, but stories already made still count toward points. Pinned in Task 4 (points with `storiesOn=false`) and Task 8 (E2E).

- [ ] **Step 5: Create `child/wardrobe.ts`**

```ts
import { z } from "zod";
import data from "@/content/room/wardrobe.json";
import type { AssetId } from "@/design/asset-ids";

// My room (D-074): the wearable items, in unlock order, and the unlock maths. Client-safe: shared by
// the room UI, the Avatar layers and the server validator. Nothing here is personal data.

export const WEAR_SLOTS = ["head", "face", "neck", "back"] as const;
export type WearSlot = (typeof WEAR_SLOTS)[number];
export type Placement = { x: number; y: number; w: number; rotate: number; behind: boolean };
export type WearItem = { id: string; slot: WearSlot; asset: AssetId; en: string; ar: string; placement: Placement; provisional: boolean };

export const WEAR_ITEMS = data.items as WearItem[];
/** Items open from the start, so dress-up works on day one. */
export const FREE_ITEMS = 2;
/** Points per further item. */
export const POINTS_PER_ITEM = 3;
/** Distinct feelings in the story list: the most the feelings source can give. */
const MAX_FEELINGS = 8;

export function itemById(id: string): WearItem | undefined {
  return WEAR_ITEMS.find((i) => i.id === id);
}

/** 1 per story made, 1 per distinct feeling met (at most 8), 2 per finished level. */
export function rewardPoints(p: { stories: number; feelings: number; levels: number }): number {
  return p.stories + Math.min(p.feelings, MAX_FEELINGS) + 2 * p.levels;
}

/** How many items these points open (free items included), capped at the wardrobe's size. */
export function unlockedCount(points: number): number {
  return Math.min(WEAR_ITEMS.length, FREE_ITEMS + Math.floor(points / POINTS_PER_ITEM));
}

/** Steps (points) still needed for the next item after `reached`; null when everything is open. */
export function stepsToNext(points: number, reached: number): number | null {
  if (reached >= WEAR_ITEMS.length) return null;
  const needed = (reached - FREE_ITEMS + 1) * POINTS_PER_ITEM;
  return Math.max(1, needed - points);
}

const idsFor = (slot: WearSlot) => WEAR_ITEMS.filter((i) => i.slot === slot).map((i) => i.id) as [string, ...string[]];

/** What the character wears: at most one item per body area, each from that area's list. */
export const wearSchema = z
  .object({
    head: z.enum(idsFor("head")).optional(),
    face: z.enum(idsFor("face")).optional(),
    neck: z.enum(idsFor("neck")).optional(),
    back: z.enum(idsFor("back")).optional(),
  })
  .strict();
export type Wear = z.infer<typeof wearSchema>;
```

- [ ] **Step 3: Add `wornLayers`** to `child/wardrobe.ts`

```ts
/** The worn items to draw, behind and in front of the body; items without delivered art are left out. */
export function wornLayers(wear: Wear | undefined, delivered: (asset: AssetId) => boolean): { behind: WearItem[]; front: WearItem[] } {
  const items = WEAR_SLOTS.map((s) => (wear?.[s] ? itemById(wear[s]!) : undefined)).filter((i): i is WearItem => !!i && delivered(i.asset));
  return { behind: items.filter((i) => i.placement.behind), front: items.filter((i) => !i.placement.behind) };
}
```

```ts
import "server-only";
import { and, count, eq, lt, sql } from "drizzle-orm";
import { z } from "zod";
import { db } from "@/platform/db/client";
import { childProfile, story } from "@/platform/db/schema";
import { decryptField } from "@/platform/crypto";
import { AVATAR_COLOURS } from "@/design/asset-ids";
import { DEFAULT_AVATAR, INTERESTS, MAX_INTERESTS, NICKNAME_KEYS, avatarSchema, nicknameWord, type Avatar, type Interest } from "./options";
import { FREE_ITEMS, WEAR_ITEMS, WEAR_SLOTS, itemById, rewardPoints, stepsToNext, unlockedCount } from "./wardrobe";
import { collection, type Collection } from "./collection";
import { getWorldState } from "./progress";

// My room (D-074), child scope, server-only. Points come from data other features already store
// (stories, the feelings in them, finished levels); the profile keeps only the highest unlock count ever
// reached and how many unlocks were watched, so a deleted story never takes an item away (rule 12).
// Every change is checked here (CR-2): items must be unlocked and in their own body area, names come
// from the reviewed list or the parent's nickname, likes from the list.

export const roomUpdateSchema = z.discriminatedUnion("action", [
  z.strictObject({ action: z.literal("wear"), slot: z.enum(WEAR_SLOTS), item: z.enum(WEAR_ITEMS.map((i) => i.id) as [string, ...string[]]).nullable() }),
  z.strictObject({ action: z.literal("colour"), colour: z.enum(AVATAR_COLOURS) }),
  z.strictObject({ action: z.literal("nickname"), nickname: z.union([z.enum(NICKNAME_KEYS as [string, ...string[]]), z.literal("parent")]) }),
  z.strictObject({ action: z.literal("interests"), interests: z.array(z.enum(INTERESTS)).max(MAX_INTERESTS) }),
  z.strictObject({ action: z.literal("seen") }),
]);
export type RoomUpdate = z.infer<typeof roomUpdateSchema>;

export type RoomState = {
  avatar: Avatar;
  nicknameKey: string | null;
  name: string | null;
  parentNickname: string | null;
  interests: Interest[];
  points: number;
  reached: number;
  seen: number;
  stepsToNext: number | null;
  places: Collection["places"];
  feelings: Collection["feelings"];
  /** The number of the child's books, or null when the parent has Stories off. */
  books: number | null;
};

async function profile(childId: string) {
  const [p] = await db.select().from(childProfile).where(eq(childProfile.id, childId)).limit(1);
  if (!p) throw new Error("child not found");
  return p;
}

/** Points from what is stored now, and the reached count raised to match (never lowered). */
async function refresh(childId: string) {
  const world = await getWorldState(childId);
  const col = await collection(childId, world, true);
  const [{ n }] = await db.select({ n: count() }).from(story).where(eq(story.childId, childId));
  const levels = col.places.flatMap((p) => p.levels).filter((l) => l.done).length;
  const points = rewardPoints({ stories: Number(n), feelings: col.feelings.filter((f) => f.met).length, levels });
  const computed = unlockedCount(points);
  await db.update(childProfile).set({ rewardsReached: sql`greatest(${childProfile.rewardsReached}, ${computed})` }).where(eq(childProfile.id, childId));
  return { points, col, stories: Number(n) };
}

export async function roomState(childId: string, storiesOn: boolean): Promise<RoomState> {
  const { points, col, stories } = await refresh(childId);
  const p = await profile(childId);
  const parsed = avatarSchema.safeParse(p.avatar);
  const avatar = parsed.success ? { ...parsed.data, wear: parsed.data.wear ?? {} } : { ...DEFAULT_AVATAR, wear: {} };
  const parentNickname = p.nicknameEnc ? decryptField(p.nicknameEnc) : null;
  const reached = Math.max(p.rewardsReached, FREE_ITEMS);
  return {
    avatar,
    nicknameKey: p.nicknameKey,
    name: p.nicknameKey === "parent" ? parentNickname : nicknameWord(p.nicknameKey, p.locale),
    parentNickname,
    interests: (p.interests ?? []) as Interest[],
    points,
    reached,
    seen: Math.min(Math.max(p.rewardsSeen, FREE_ITEMS), reached),
    stepsToNext: stepsToNext(points, reached),
    places: col.places,
    feelings: col.feelings,
    books: storiesOn ? stories : null,
  };
}

export async function applyRoomUpdate(childId: string, u: RoomUpdate): Promise<{ ok: true; opened?: string } | { ok: false }> {
  const p = await profile(childId);
  const current = avatarSchema.safeParse(p.avatar);
  const avatar: Avatar = current.success ? current.data : DEFAULT_AVATAR;
  switch (u.action) {
    case "wear": {
      const wear = { ...(avatar.wear ?? {}) };
      if (u.item === null) {
        delete wear[u.slot];
      } else {
        const item = itemById(u.item);
        await refresh(childId);
        const reached = Math.max((await profile(childId)).rewardsReached, FREE_ITEMS);
        const index = WEAR_ITEMS.findIndex((i) => i.id === u.item);
        if (!item || item.slot !== u.slot || index >= reached) return { ok: false };
        wear[u.slot] = item.id;
      }
      await db.update(childProfile).set({ avatar: { ...avatar, wear } }).where(eq(childProfile.id, childId));
      return { ok: true };
    }
    case "colour":
      await db.update(childProfile).set({ avatar: { ...avatar, colour: u.colour } }).where(eq(childProfile.id, childId));
      return { ok: true };
    case "nickname":
      if (u.nickname === "parent" && !p.nicknameEnc) return { ok: false };
      await db.update(childProfile).set({ nicknameKey: u.nickname }).where(eq(childProfile.id, childId));
      return { ok: true };
    case "interests":
      await db.update(childProfile).set({ interests: u.interests }).where(eq(childProfile.id, childId));
      return { ok: true };
    case "seen": {
      await refresh(childId);
      // One unlock per call, and never past what was reached (a double tap can't skip one).
      const rows = await db
        .update(childProfile)
        .set({ rewardsSeen: sql`greatest(${childProfile.rewardsSeen}, ${FREE_ITEMS}) + 1` })
        .where(and(eq(childProfile.id, childId), lt(sql`greatest(${childProfile.rewardsSeen}, ${FREE_ITEMS})`, childProfile.rewardsReached)))
        .returning({ seen: childProfile.rewardsSeen });
      if (!rows.length) return { ok: false };
      return { ok: true, opened: WEAR_ITEMS[rows[0].seen - 1].id };
    }
  }
}
```

```ts
import { NextResponse, type NextRequest } from "next/server";
import { getChild } from "@/auth/guards";
import { applyRoomUpdate, roomUpdateSchema } from "@/child/room";
import { env } from "@/platform/env";

// Child scope. My room changes (D-074): worn items, colour, name and likes, from fixed lists only, and
// opening one unlocked surprise. Locked items are refused here, not just hidden in the UI (CR-2).
export async function POST(request: NextRequest) {
  if (request.headers.get("origin") !== env().APP_ORIGIN) return NextResponse.json({ error: "forbidden" }, { status: 403 });
  const child = await getChild();
  if (!child) return NextResponse.json({ error: "unauthorized" }, { status: 401 });
  let body: unknown;
  try {
    body = await request.json();
  } catch {
    return NextResponse.json({ error: "invalid" }, { status: 400 });
  }
  const parsed = roomUpdateSchema.safeParse(body);
  if (!parsed.success) return NextResponse.json({ error: "invalid" }, { status: 400 });
  const r = await applyRoomUpdate(child.childId, parsed.data);
  return r.ok ? NextResponse.json(r) : NextResponse.json({ error: "invalid" }, { status: 400 });
}
```

```ts
import type { RoomUpdate } from "@/child/room";

/** Saves a room change; retries once after a short pause. The child never sees an error. */
export async function saveRoom(update: RoomUpdate): Promise<{ ok: boolean; opened?: string }> {
  for (let attempt = 0; attempt < 2; attempt++) {
    try {
      const res = await fetch("/api/child/room", { method: "POST", headers: { "content-type": "application/json" }, body: JSON.stringify(update) });
      if (res.ok) return { ok: true, ...((await res.json()) as { opened?: string }) };
      if (res.status === 400) return { ok: false }; // refused (e.g. locked): no retry
    } catch {
      // network: try once more
    }
    await new Promise((r) => setTimeout(r, 1500));
  }
  return { ok: false };
}
```
